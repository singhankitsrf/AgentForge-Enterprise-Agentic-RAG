## Portfolio capability map

- **Agentic / GenAI:** LangGraph, LangChain, MCP, RAG, tool governance, human approval, evaluation
- **Digital-health product engineering:** role-aware journeys, scheduling, stateful consultation workflow, browser communication, operational administration
- **Computer vision / Healthcare AI:** leakage-aware imaging pipeline, calibration, uncertainty routing, explainability
- **AWS AI platform:** SageMaker Pipelines, Model Registry, async inference, serverless workflow, Terraform
- **NLP ReleaseOps:** reproducible modeling, regression gates, security checks, portable inference, CI/CD
- **Azure data platform:** PySpark, Databricks, Delta Lake, streaming, medallion architecture, data quality

## Engineering standards used across the portfolio

1. Reproducible CI and deterministic checks wherever practical.
2. Executed evidence is separated from architecture intent.
3. Cloud, clinical, performance, cost, and reliability claims are published only when measured.
4. Every flagship project has a project charter and actionable roadmap/evidence path.
5. Responsible-AI, data-governance, privacy and security boundaries are documented rather than implied.
